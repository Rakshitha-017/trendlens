# TrendLens Frontend
TrendLens is a visual trend detection platform that helps users discover, analyze, and understand emerging trends from images and multimedia content. Unlike traditional trend analysis tools that rely primarily on text, hashtags, or captions, TrendLens focuses on visual patterns to identify trends at an earlier stage.

This repository contains the frontend of the TrendLens project, providing an intuitive and responsive user interface for uploading images, interacting with AI-powered insights, and visualizing trend analysis. The application is designed to integrate seamlessly with a backend service for image processing, AI inference, and data analytics.

Built with

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Installation

npm install

## Run

npm run dev

## Build

npm run build
